ФИНАНСЫ ПО ЗАКАЗАМ — ИСПРАВЛЕНИЕ ПОДКЛЮЧЕНИЯ GOOGLE ДИСКА
13.10.2026

ЧТО ИСПРАВЛЕНО
1. Повторная авторизация Google больше не использует обработчик от первого входа.
2. Когда временный токен Google истёк, кнопка «Подключить Google» доступна на любой странице, без перехода в настройки.
3. После возвращения в Android-приложение статус подключения обновляется.
4. Повторное разрешение Google запрашивается без обязательного повторного выбора аккаунта, если доступ уже предоставлялся.
5. В Настройках добавлен «Диагностика → Скачать отчёт» (без сумм и заказов).
6. Обновлена версия офлайн-кэша для правильного получения исправленных файлов.

ВАЖНО
- Токен Google по-прежнему временный: из соображений безопасности Google может попросить нажать «Подключить Google» после перезапуска приложения и по истечении срока токена.
- Это не новая база и не изменение структуры данных. Все записи и сам Google Диск остаются прежними.
- НЕ УДАЛЯЙТЕ установленное Android-приложение, кэш сайта или локальное хранилище, пока имеются несинхронизированные операции.
- НЕ загружайте на GitHub файлы finance.sqlite3, IMPORT_IZ_WINDOWS.json и другие финансовые данные.

КАК ОБНОВИТЬ НА GITHUB
1. Откройте репозиторий: https://github.com/farhodkb-oss/finansy-po-zakazam
2. Нажмите Add file → Upload files.
3. Распакуйте этот ZIP на компьютере.
4. Загрузите из распакованной папки ТОЛЬКО файл sw.js и папку assets с двумя файлами:
   assets/app.js
   assets/drive_api.js
   sw.js
   Сохраняйте эти пути: app.js и drive_api.js должны попасть в папку assets, а sw.js — в корень репозитория.
5. Нажмите Commit changes. Если GitHub предупреждает о замене существующих файлов — подтвердите.
6. Подождите успешного обновления GitHub Pages (Actions или Settings → Pages).
7. На Android закройте и снова откройте PWA; при необходимости откройте сайт в Chrome и нажмите «Обновить».
8. Если Google отключился — нажмите «Подключить Google» на главной странице и подтвердите вход.

НЕ МЕНЯЙТЕ
assets/google_config.js — там ваш Client ID, он уже настроен!
Google Cloud, OAuth Client ID и папку в Google Диске менять не надо.

ПРОВЕРКА
1. Проверьте данные: 2 заказа, приход 50 630 000 сум, расход 26 462 000 сум (до новых операций).
2. Создайте тестовую запись, дождитесь синхронизации и проверьте появление на втором устройстве.
3. Если продолжает закрываться, Настройки → Диагностика → Скачать отчёт; пришлите файл и опишите, закрывается приложение целиком или просто пропадает подключение.

ПРИМЕЧАНИЕ
Полностью незаметное продление OAuth-токена без участия пользователя в данной PWA/Google Identity Services Token Model недоступно. Для постоянной фоновой авторизации потребуется серверная архитектура с OAuth Authorization Code и безопасным хранением refresh-token.
