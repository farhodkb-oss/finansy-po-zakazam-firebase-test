ФИНАНСЫ ПО ЗАКАЗАМ — GITHUB PAGES
================================

Этот архив — статический сайт, совместимый с адресами вида:
https://ВАШ_ЛОГИН.github.io/finansy-po-zakazam/

ВАЖНО: финансовых данных и секретов в архиве НЕТ.
Ваши данные остаются в Google Диске, а работающая локальная версия на
Windows по адресу localhost:8000 продолжает действовать независимо.

ПЕРЕД ЗАГРУЗКОЙ
---------------
1. Откройте у себя на компьютере файл
   C:\MY PROGRAMM\FINANSY_GOOGLE_DRIVE\public\assets\google_config.js
2. Скопируйте из него ТОЛЬКО значение Client ID — строку, которая
   заканчивается на .apps.googleusercontent.com.
3. Откройте файл assets\google_config.js ИЗ ЭТОГО АРХИВА
   (после распаковки) и впишите тот же Client ID вместо заглушки.
   Это публичный Client ID. Client Secret никуда НЕ вставляйте.
4. Не загружайте в GitHub finance.sqlite3, IMPORT_IZ_WINDOWS.json,
   резервные копии, журналы ошибок или реальные финансовые данные.

GITHUB: ПОШАГОВО
----------------
1. Войдите на https://github.com и нажмите + -> New repository.
2. Имя: finansy-po-zakazam. Видимость: Public (GitHub Free).
   README и остальные начальные файлы можно не создавать.
3. Откройте новый репозиторий -> Add file -> Upload files.
4. Перетащите СОДЕРЖИМОЕ распакованной папки, чтобы index.html,
   sw.js и manifest.webmanifest были в корне репозитория.
   Папка assets должна находиться рядом с index.html.
   Файл .nojekyll рекомендуется также загрузить.
5. Нажмите Commit changes.
6. Перейдите Settings -> Pages. Source: Deploy from a branch.
   Branch: main; folder: /(root). Нажмите Save.
7. Дождитесь публикации. В разделе Pages появится HTTPS-ссылка:
   https://ВАШ_ЛОГИН.github.io/finansy-po-zakazam/

GOOGLE CLOUD: РАЗРЕШИТЕ НОВЫЙ АДРЕС
-----------------------------------
1. https://console.cloud.google.com/auth/clients
2. Выберите проект FinansyPoZakazam.
3. Откройте существующий OAuth-клиент «Finansy Po Zakazam».
4. В Authorized JavaScript origins добавьте:
   https://ВАШ_ЛОГИН.github.io
   НЕ добавляйте /finansy-po-zakazam — путь не разрешён.
5. Сохраните. Старое значение http://localhost:8000 оставьте.
6. Откройте опубликованную ссылку, нажмите «Подключить Google Диск»,
   используйте тот же Google-аккаунт, дождитесь синхронизации.

ПРОВЕРЬТЕ ПЕРЕД РАБОТОЙ С РЕАЛЬНЫМИ ДАННЫМИ
-------------------------------------------
- На новом сайте должны отображаться те же 2 заказа и суммы,
  что на Windows (но не редактируйте реальные операции для теста).
- Сделайте резервную копию JSON через раздел «Настройки».
- Проверьте создание/удаление ОДНОГО тестового заказа и восстановление
  из Google Диска на втором браузере / телефоне.
- Для офлайн-работы сначала откройте сайт при работающем интернете
  и убедитесь, что служебный кэш установился.
- На Android откройте сайт в Chrome -> меню ⋮ -> «Установить приложение»
  или «Добавить на главный экран» (зависит от телефона/браузера).

ВНИМАНИЕ: GitHub Pages публикует интерфейс в интернете — это не
приватный сервер. При этом JSON c финансами не публикуется на GitHub:
доступ к нему по-прежнему требует вашей авторизации Google.
Код сайта и публичный Client ID будет видно посетителям репозитория.
OAuth токен хранится в памяти браузера. Берегите свой Google-аккаунт
и включите двухфакторную аутентификацию.

НОВЫЙ АДРЕС = НОВАЯ ЛОКАЛЬНАЯ КОПИЯ:
localhost и сайт github.io имеют разные локальные хранилища. Данные
появятся на GitHub-сайте только после входа в тот же Google-аккаунт и
полной синхронизации. Не импортируйте IMPORT_IZ_WINDOWS.json повторно.

Это версия для тестирования. Размещение в GitHub и реальную авторизацию
в вашем аккаунте нужно проверить отдельно.
