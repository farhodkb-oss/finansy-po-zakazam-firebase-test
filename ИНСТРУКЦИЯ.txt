ИСПРАВЛЕНИЕ ЗАГРУЗКИ ТАБЛИЦЫ «ОПЛАТА ПО ЗАКАЗАМ»

Причина: Firebase-проект в разное время загружал JavaScript
из двух возможных мест: app.js и assets/app.js.
Этот патч принудительно загружает новый файл с УНИКАЛЬНЫМ именем,
так что заменять прежний app.js не нужно.

Куда загружать:
https://github.com/farhodkb-oss/finansy-po-zakazam-firebase-test
Именно КОРЕНЬ репозитория (где лежит index.html), ветка main.

ФАЙЛЫ ДЛЯ ЗАГРУЗКИ (все четыре за один раз):
1. index.html
2. sw.js
3. app_payments_20261014.js
4. styles_payments_20261014.css

Что делать:
- На телефоне распаковать ZIP через «Мои файлы».
- На GitHub открыть репозиторий, Add file -> Upload files.
- Загрузить все четыре файла и нажать Commit changes.
- Дождаться успешного Pages build в разделе Actions.
- Открыть https://farhodkb-oss.github.io/finansy-po-zakazam-firebase-test/
- Перейти в «Заказы». Должны появиться «Получено, сум»,
  «Осталось, сум» и «Оплата».

Проверка публикации без входа в приложение:
Откройте адрес:
https://farhodkb-oss.github.io/finansy-po-zakazam-firebase-test/app_payments_20261014.js
В этом файле на странице браузера найдите фразу «Получено, сум».

НЕ УДАЛЯЙТЕ IndexedDB, кэш/данные сайта или приложение.
НЕ ЗАГРУЖАЙТЕ finance.sqlite3, JSON с финансами и пароли.
Патч не меняет Firebase-проект, Firestore, UID и записи в базе.
