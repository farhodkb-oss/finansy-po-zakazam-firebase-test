ИСПРАВЛЕНИЕ ОБНОВЛЕНИЯ КЭША (GitHub Pages)

Проблема: GitHub обновил assets/app.js и assets/drive_api.js, но браузер продолжал использовать старые копии из PWA-кэша.

ШАГИ:
1. В репозитории https://github.com/farhodkb-oss/finansy-po-zakazam откройте корень (не папку assets).
2. Add file -> Upload files.
3. Загрузите ДВА файла из этого архива: index.html и sw.js.
4. Нажмите Commit changes.
5. Дождитесь зелёной отметки Pages build and deployment в Actions.
6. Откройте https://farhodkb-oss.github.io/finansy-po-zakazam/ в Chrome.
7. На Windows обновите Ctrl+Shift+R. Если после первого обновления не изменилось, подождите 10-20 секунд и обновите ещё раз.
8. При статусе «Google Диск не подключён» должна появиться кнопка «Подключить Google» вместо «Обновить». Нажмите её для повторного входа.

ВАЖНО: Не загружайте finance.sqlite3, IMPORT_IZ_WINDOWS.json, google_config.js или папку с данными.
Не удаляйте PWA, не очищайте данные сайтов, не сбрасывайте браузер. Эти действия могут уничтожить несинхронизированные изменения.
Исправление меняет только браузерный кэш и загрузку скриптов, НЕ добавляет автоматическое постоянное продление OAuth-токена.
Ваша локальная база и данные Google Диска не изменяются.
