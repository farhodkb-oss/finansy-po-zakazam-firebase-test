ФИНАНСЫ ПО ЗАКАЗАМ — Firebase
Обновление: себестоимость, денежный результат, сроки исполнения, долги

ВАЖНО: обновляем только тестовый репозиторий Firebase:
https://github.com/farhodkb-oss/finansy-po-zakazam-firebase-test

1. Перед обновлением дождитесь статуса «Синхронизировано».
2. В «Настройки» выполните «Скачать JSON» и сохраните резервную копию вне GitHub.
3. Распакуйте этот ZIP. Откройте корень тестового репозитория GitHub.
4. В корне репозитория выберите Add file → Upload files.
5. Загрузите именно ЧЕТЫРЕ файла:
   index.html
   sw.js
   app_costs_deadlines_20261014.js
   styles_costs_deadlines_20261014.css
   Никаких финансовых баз, JSON-резервных копий или паролей не загружайте.
6. Нажмите Commit changes и дождитесь зелёного статуса GitHub Pages.
7. Обновите страницу сайта, не удаляя данные браузера/приложение.
   https://farhodkb-oss.github.io/finansy-po-zakazam-firebase-test/
8. Откройте «Заказы». Должны появиться затраты, денежный результат,
   срок исполнения, раскрываемые детали, фильтр по срокам.
9. Откройте «Изменить» для одного заказа: при необходимости укажите
   плановую себестоимость и дату исполнения, сохраните, дождитесь синхронизации.
10. Раздел «Отчёты»: новые вкладки «Долги заказчиков» (на дату)
    и «Экономика заказов» (за всё время); доступны CSV и печать в PDF.

СОВМЕСТИМОСТЬ
• Существующие заказы без полей planned_cost и due_date сохраняются без изменений.
• Новые поля необязательны и заполняются только через «Изменить заказ».
• База Firestore, Firebase Authentication, справочники и платежи не меняются.
• Старые файлы app.js и assets/app.js пока НЕ удаляйте.
• Новые файлы JavaScript/CSS имеют уникальные имена, чтобы исключить старый PWA-кэш.

ФИНАНСОВЫЕ ОПРЕДЕЛЕНИЯ
• Получено: платежи/авансы по заказу минус возвраты заказчику.
• Долг: максимум из 0 и разницы договор−получено.
• Учтённые затраты: все расходы, привязанные к заказу, кроме возвратов заказчику.
• Плановая прибыль = договор − введённая плановая себестоимость.
• Предварительная маржа = договор − уже учтённые затраты.
• Денежный результат = получено − уже учтённые затраты.
• Общие расходы без привязки к заказам не распределяются автоматически.
  Эти расчёты не заменяют бухгалтерский учёт и не отражают будущие расходы.
• «Просрочен» относится только к сроку ИСПОЛНЕНИЯ, не к сроку платежа.
• Отчёт «Долги заказчиков» показывает задолженность на выбранную дату
  с учётом текущей стоимости договора и оплат, совершённых к этой дате.
