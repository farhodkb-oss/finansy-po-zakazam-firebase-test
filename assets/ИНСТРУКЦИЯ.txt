На GitHub в assets/app.js и assets/drive_api.js ещё лежали старые файлы,

КАК ИСПРАВИТЬ
1. Откройте https://github.com/farhodkb-oss/finansy-po-zakazam
2. В репозитории войдите в папку assets.
3. Находясь ВНУТРИ папки assets, нажмите Add file -> Upload files.
4. Загрузите ДВА файла из этого архива: app.js и drive_api.js.
   НЕ загружайте их в корень репозитория — они должны заменить
   assets/app.js и assets/drive_api.js.
5. Нажмите Commit changes и дождитесь публикации GitHub Pages.
6. На компьютере откройте страницу программы, нажмите Ctrl+Shift+R.
   При статусе «Google Диск не подключён» в верхней панели должна появиться
   кнопка «Подключить Google».
7. На Android закройте и откройте установленную программу с интернетом.
   Если обновление не пришло, откройте сайт в Chrome и обновите его.

ТЕКУЩАЯ СИТУАЦИЯ:
Google OAuth токен временный и при перезапуске браузера может потребоваться
повторное подключение. Это исправление облегчает переподключение и устраняет
ошибку повторной авторизации, но НЕ обеспечивает вечный Google сеанс.
Для входа без повторных запросов потребуется серверная авторизация.

НЕ ТРОГАЙТЕ: finance.sqlite3, Google Drive event_*.json,
IMPORT_IZ_WINDOWS.json, google_config.js. Не очищайте данные приложения,
пока есть неотправленные операции.
