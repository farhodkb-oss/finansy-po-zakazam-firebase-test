ИСПРАВЛЕНИЕ «ФИНАНСЫ ПО ЗАКАЗАМ» — FIREBASE (ОКТЯБРЬ 2026)
=============================================================================
Это обновление ДЛЯ ТЕСТОВОГО репозитория с ПЛОСКОЙ структурой файлов:
https://github.com/farhodkb-oss/finansy-po-zakazam-firebase-test

Внутри архива 4 файла:
  app.js            расчёт и вывод отчётов, график 7 дней
  styles.css        оформление новых отчётов и графика
  index.html        принудительная загрузка обновлённых JS и CSS
  sw.js             обновлённый офлайн-кэш PWA

ПОШАГОВО НА ANDROID
1. Откройте действующую Firebase-программу и дождитесь «Синхронизировано».
2. Настройки → Скачать JSON. Сохраните копию и не публикуйте её в GitHub.
3. Распакуйте архив в «Мои файлы» → Загрузки.
4. Откройте GitHub → finansy-po-zakazam-firebase-test (НЕ репозиторий Google Drive).
5. На странице репозитория нажмите Add file → Upload files.
6. Загрузите только файлы app.js, styles.css, index.html, sw.js.
   Все четыре должны находиться в КОРНЕ репозитория — без дополнительных папок.
   При перезаписи GitHub может не показывать отдельный запрос «Заменить».
7. Commit changes. Проверьте, что у файлов изменилось время последнего коммита.
8. Подождите GitHub Actions → pages build and deployment (зелёная галочка).
9. Откройте адрес:
   https://farhodkb-oss.github.io/finansy-po-zakazam-firebase-test/
10. На Android обновите страницу; если стоит PWA, закройте и запустите её снова.
    НЕ ОЧИЩАЙТЕ кэш и данные сайта вручную при несинхронизированных изменениях.

В РАЗДЕЛЕ «ОТЧЁТЫ»
• Выберите «Движение денег» или «По заказам».
• Выберите даты «Период с» и «Период по», можно выбрать «Сегодня»,
  «7 дней», «Этот месяц» или «Всё время».
• В движении денег отображаются все операции и промежуточный остаток,
  а также начальный и конечный остаток за период.
• Можно выбрать один заказ, общие операции или все заказы.
• CSV выгружает строки текущего отчёта.
• PDF: «Печать / PDF» → системное меню → «Сохранить как PDF».

НА ГЛАВНОЙ
• 7 дней, две колонки на день: зелёная — приход, красная — расход.
• Суммы за 7 дней в легенде. Нажмите на дату, чтобы увидеть точные суммы.

Сохранены существующие Firebase Authentication, Firestore, база, справочники.
Файлы не содержат миграций и не меняют ни одну запись в Cloud Firestore.
Расчётный остаток — не остаток банка без ввода начального сальдо.

Проверен JavaScript синтаксис и математические тесты отчётов.
В реальном Android/browser обновление требуется дополнительно проверить.
