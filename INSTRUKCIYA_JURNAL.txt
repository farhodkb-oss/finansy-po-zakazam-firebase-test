ОБНОВЛЕНИЕ FIREBASE — ЖУРНАЛ ОПЕРАЦИЙ: ПО УМОЛЧАНИЮ СЕГОДНЯ

Назначение:
- При открытии «Операции» показываются только операции за сегодня.
- Можно выбрать любой день через календарь.
- Быстрые кнопки: Сегодня, Вчера, 7 дней, Этот месяц, Выбрать период, Все даты.
- В журнале показываются количество операций, итог прихода и расхода по текущему фильтру.
- Выбор даты в журнале НЕ меняет период на главной странице и в «Отчётах».
- Даты операций в базе не редактируются автоматически; меняется только список на экране.

УСТАНОВКА С ANDROID:
1. Убедитесь, что старые операции синхронизированы с Firebase.
2. Распакуйте ZIP в приложении «Мои файлы» на телефоне.
3. Откройте ТОЛЬКО ТЕСТОВЫЙ репозиторий:
   https://github.com/farhodkb-oss/finansy-po-zakazam-firebase-test
4. Перейдите в корень репозитория (НЕ в assets).
5. Нажмите Add file → Upload files и выберите ЧЕТЫРЕ файла:
   app.js, styles.css, index.html, sw.js
6. Сохраните изменения кнопкой Commit changes.
7. Дождитесь успешной публикации в Actions (Pages build and deployment).
8. Откройте:
   https://farhodkb-oss.github.io/finansy-po-zakazam-firebase-test/
   и перезагрузите страницу. Откройте «Операции».

ВНИМАНИЕ: Инструкция предназначена для «плоской» телефонной сборки,
где index.html загружает ./app.js и ./styles.css из КОРНЯ.
Если ваша версия загружает ./assets/app.js — не перемещайте файлы
наугад: сначала проверьте index.html и обратитесь за нужным патчем.

НЕ ЗАГРУЖАЙТЕ в GitHub файлы JSON с финансовыми данными, пароли,
секреты и базу finance.sqlite3. Не очищайте данные приложения до
завершения синхронизации. Изменения только в интерфейсе и фильтрации,
структура Cloud Firestore не меняется.

Проверки: синтаксис app.js/sw.js (Node.js), фильтр сегодня,
произвольный день, диапазон, пресеты, запрет неверного периода,
неизменность периода отчётов. Реальная установка на Android не проверена.
